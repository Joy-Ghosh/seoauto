# Project phases

## Phase one: private SEO workspace

- Reviewable crawls of public websites, page evidence and transparent audit findings.
- Redirect-alias deduplication, verified internal-error findings and internal-link connections.
- Nine NVIDIA research tasks: keyword ideas, competitor gaps, content plans, page improvements, ordered SEO actions, content briefs, internal links, structured data and site questions.
- Task-specific output restrictions, constrained JSON, source-page provenance and reviewable title/description drafts.
- Hosted owner access, session-isolated credentials, public-network-only crawling and resource limits.
- Browser-local history, scan backup/import, HTML/CSV/Markdown exports and a downloadable WordPress companion.
- Private GitHub source and a protected Vercel deployment, once account setup permits publication.

## Phase two: ChatGPT MCP connection — not implemented yet

1. Add durable project/scan/report storage with per-user ownership. Browser storage alone cannot serve a remote MCP client.
2. Add OAuth with narrow read/research scopes, revocation, consent and usage limits. The browser workspace password is not the future MCP authentication mechanism.
3. Expose typed tools for sites, scans, evidence, findings and research. Reuse the existing audit and research core rather than scraping the UI.
4. Keep publishing separate from discovery. Any eventual write tool needs explicit review/approval, ownership checks, original-value conflict detection and recovery records.
5. Verify the ChatGPT connection and tool flows end to end before making them available beyond the owner.

No MCP endpoint, OAuth registration, public user signup or automatic website publishing is included in phase one.
