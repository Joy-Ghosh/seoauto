From a URL to reviewed changes

Start with a scan

Enter a website URL, choose a page limit, and select Scan website. The sample audit lets you learn the workflow without crawling a real site.

You can fix metadata manually from a page drawer. AI is optional. The scan selector at the top reopens saved scans; Import & backup transfers a scan between browsers or runtimes.

The crawler reads response HTML and respects robots.txt. It does not execute website JavaScript, measure rankings, or retrieve keyword search volumes. Suggested competitors need verification.

The code follows the same journey

One interface, two runtimes

The client adapter routes local requests to the Node server. Hosted mode uses a stateless Vercel handler, streams scan evidence, and stores completed scans in this browser.

Vercel holds the app secrets in server environment variables. These are separate from your NVIDIA key.

Local and live history do not sync automatically

Drafts and research preferences use browser localStorage. Hosted scans and reports use IndexedDB. A different browser, origin or cleared storage has a different history. Export a backup before clearing browser data; import it in the other workspace.

Both runtimes use the shared crawler, analyzer and AI validation code. The live handler restricts destinations to public network addresses. Requests to NVIDIA share the selected scan evidence only after you choose the data-sharing checkbox.

Three priorities now included

  1. Measured search opportunitiesWebsite audit → Search Console offers CSV import, read-only Google connection, or skip. CSV works immediately; Google sign-in needs the app owner's OAuth configuration. Metrics describe loaded rows and stay separate from AI ideas.
  2. Verify changes after publishingSaved changes shows exact original and proposed values. Apply an approved fix in your CMS, then select Re-scan this page & verify. The console starts a one-page scan, selects the baseline and compares expected/observed values. Cross-page or unscanned-destination checks remain unverified when coverage is insufficient.
  3. Generate fixes beside their evidenceOpen a page for Problems, Link structure and Page skeleton. Generate H1, title, description or user-described alt drafts. Generate titles filters multiple pages by URL category or title problem, supports up to ten sequential requests, and lets you edit/review suggestions before saving. Empty or conflicting selected titles cannot be saved. Detect technology now inspects public headers, HTML and bounded first-party script text.

Competitor research that leads to a change

Choose a seed query and market, validate actual competing pages in search, then supply up to two URLs in AI tools → Competitors & gaps. The report compares fetched evidence and proposes own-site improvements, content/intent gaps, donor/receiver/anchor ideas and verification steps. Model-only competitor ideas remain unverified; sampled absence does not establish a site-wide gap.

Free tools worth adding next

PageSpeed Insights API for measured performance, Lighthouse for local/worker audits, and Wappalyzergo for broader fingerprint coverage. These are researched options, not installed integrations. API quotas and upstream fingerprint-data licenses need review.

Google OAuth credentials are not bundled. H1/link/server changes are applied in your editor or hosting system. No automatic website publishing, cloud history synchronization or ChatGPT MCP endpoint is present.
